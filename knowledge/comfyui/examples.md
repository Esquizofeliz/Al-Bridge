# Exemplos — ComfyUI

## Workflow de imagem conhecido
Se workflow contém nós de codificação de texto positivo/negativo e checkpoint FLUX, o Bridge pode preparar texto adequado ao modelo e orientar o usuário a colá-lo no nó correspondente. Não inventar sampler ou nomes de nós.

## Workflow desconhecido
Pedido: “Faça um prompt para meu workflow de vídeo.”
Resposta correta: pedir JSON do workflow ou declarar que só é possível entregar prompt genérico; não presumir nós ou parâmetros.
