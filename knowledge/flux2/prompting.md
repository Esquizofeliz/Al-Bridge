# Como escrever prompts para FLUX.2 Klein 9B

## Texto para imagem
Organize a descrição em linguagem natural:
1. Sujeito principal e características.
2. Ação, pose e expressão.
3. Ambiente, época e objetos.
4. Enquadramento, perspectiva e composição.
5. Iluminação, paleta, materiais e textura.
6. Direção estética/fotográfica.

Evite palavras contraditórias. Priorize elementos essenciais e relações espaciais claras.

## Edição com referência
- Identifique a imagem como referência.
- Diga o que deve mudar.
- Diga o que deve permanecer: aparência, roupa, pose, enquadramento, paleta ou cenário.
- Não descreva como existente detalhe não visível.
- Preservação perfeita de identidade ou pixels é objetivo, não garantia.

## Múltiplas referências
Atribua função a cada imagem (personagem, roupa, cenário). Não presuma que a interface local aceite várias imagens sem conferir.

O prompt é separado da imagem: o usuário precisa anexar a referência ao pipeline FLUX. A análise do Qwen não substitui essa entrada.
